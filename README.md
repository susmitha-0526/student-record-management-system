
# Student Record Management System

A command-line Python app to manage student records with full CRUD support, storing data in JSON and exporting to CSV.

## Concepts Used
- Functions, parameters, return values
- Lambda functions (sorting toppers) and list comprehensions (search, average)
- File handling with JSON and CSV
- Exception handling: `try-except-finally`, input validation

## Features
- Add, view, update, delete students
- Search by name
- Top 3 students and class average
- Export to CSV
- Data saved automatically in `students.json`

## Run
```bash
python main.py
```

## Sample Record
```json
{"id": 1, "name": "Asha", "age": 20, "course": "Python", "marks": 88.5}
```
